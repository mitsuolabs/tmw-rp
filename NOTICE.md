# NOTICE

This project is a local-first browser radio client. It does not operate a backend, does not own any radio station, and does not control any third-party stream source.

## Public APIs and sources

This software may use public, network-accessible sources including, but not limited to:

- Radio Browser API
- MusicBrainz
- Wikipedia
- user-supplied direct stream URLs
- user-supplied CSV station lists

These providers are external services and their terms, access conditions, and licensing remain their own. This project makes no claim to ownership over their content, metadata, or broadcast rights.

## No server, no account, no age gate

This project is intentionally designed to run locally in the user's browser without requiring a backend, account creation, or a hosted service layer.

Because it does not host a service, does not collect or store user authentication state, and does not operate a central server, there is no meaningful reason to impose an age-gate in the same way governments may require for certain regulated broadcast systems that operate physically or centrally.

This is not a streaming platform and not a controlled broadcast network. It is a local browser interface that resolves public streams on the user's device. The project therefore does not add an age gate or identity requirement as a default posture.

## No ownership claim

This project does not own any station, channel, transmission, catalog, or content stream. It is not an operator of a broadcast network and does not assert ownership over third-party radio feeds or metadata sources.

## Audio recording note

The recording feature is a local browser-based capture feature. It records audio generated by the user’s browser session in the user's own runtime environment. This activity is consistent with general local audio capture and does not imply a platform-owned content system or redistribution service.

The project follows the principle that a user may capture and retain the audio they are already receiving through their own local device, consistent with the general legal understanding reflected in decisions such as Sony Corp. of America v. Universal City Studios, Inc. (the Betamax / time-shifting principle). This is not a broadcast ownership claim and does not change the upstream rights of any source provider.

## Privacy and telemetry

This project is designed to stay local-first and to avoid unnecessary second-party or first-party telemetry collection. There is no required account or identity layer, and the application does not require a backend to function.

The project is not designed to build a user surveillance layer, as most of our rivals do. 
It is designed as an open, user-controlled radio client.
