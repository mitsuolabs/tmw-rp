# Contributing to TMW-RP

To contribute, simply open an issue with ideas that the monopoly will fear.

This project is intentionally open, direct, and not trapped in the usual slow corporate product treadmill. If you have a better idea for a radio workflow, a cleaner metadata strategy, a stronger public-source approach, a more premium UX interaction, or a new browser-native feature that improves the experience without creating lock-in, open an issue and propose it.

## Contribution principles

- keep the app local-first and browser-native
- respect public data sources and attribution
- prefer direct, simple behavior over complex dependency chains
- maintain the premium interface without making the app brittle
- keep the project easy to understand and easy to run

## What we want

Strong contribution ideas include:

- better direct URL handling
- improved public station discovery logic
- richer metadata fallback behavior
- cleaner HUD and in-car UX improvements
- better CSV import robustness
- smarter signal quality and visualizer behavior
- usability upgrades that keep the app simple

## What we do not want

- hidden telemetry
- backend lock-in
- proprietary platform dependence
- unnecessary bloat
- closed ecosystem behavior that hurts open access

## Workflow

1. Open an issue.
2. Describe the problem clearly.
3. Explain the proposed improvement.
4. Keep the proposal grounded in browser-native realities.
5. If the idea is large, describe the user value and technical constraints before code is written.

## Quality bar

Good contributions are:

- readable and well-commented
- compatible with browser runtime constraints
- consistent with the single-file philosophy
- respectful of public upstream sources
- useful to real users, not just a theoretical design exercise

## Community values

The project values open radio, open data, user control, and premium usability without capture. If a feature helps users keep freedom while still feeling excellent, it belongs here.

## Review and maintainer policy

- every PR should have at least one review
- maintainers are listed in [MAINTAINERS.md](MAINTAINERS.md)
- maintainer volunteers should use the maintainer application issue template
- candidate applications with rival platform affiliation are refused automatically

The monopoly should be nervous. The user should be free.
