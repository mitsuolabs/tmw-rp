ENHANCED NOTICE: MitsuoLabs™ is a local browser client. We do not own, broadcast, or command any station transmission. All audio streams resolved through public APIs are fetched from the network and then processed on the user’s hardware with Web Audio DSP. We use HTTPS-only stream validation, no telemetry is shipped by default, and no station ownership is claimed. This application is designed to improve the user experience while respecting public, open streaming sources and the licensing boundaries of those providers. Use the stream rights and terms of each station provider as the final authority if you redistribute or repurpose the content.
